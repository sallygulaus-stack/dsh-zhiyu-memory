# 知鱼记忆

给 DeepSeek Harness 用的长期记忆。她记得住你说过的话，也记得清是哪一句。

「知鱼」是她的名字。

## 先说件不新鲜的事

大多数「AI 有记忆」，意思是它自己总结了一段印象存起来。

于是你会遇到三种情况：想核对，翻不到原话；它记岔了，你只能一遍遍纠正；你说「忘掉这个」，下次它照样提。

## 这里换了个做法

**每条记忆都钉着原话。**

不是「用户喜欢蓝色」，而是一句真实说过的话，加上它在哪一轮、第几个字开始、第几个字结束、那句话的哈希。想核对，点开就能看见当初那句。

记忆可以被质疑，才谈得上可靠。

**它会忘。**

关系类的东西记半年，偏好三个月，情绪两周就淡下去。半衰期按类型写在代码里，不是随机丢。

很久以前的事，她记得轮廓；昨天随口一句感慨，不会记一辈子。

**记住了的东西，改得动。**

记岔了能纠正，旧版本留在取代链里。不想再被提起，有四档可选：软删除、隐藏召回、不进导出、清除条目。

**不用额外准备任何东西。**

没有向量库，不用跑常驻服务，不用再买一份 API。数据就是一个文件夹里的几份文本，看得懂、备份得到、随时能带走。

## 装上去

从索引安装，DSH 里搜到就能装：

```text
https://raw.githubusercontent.com/sallygulaus-stack/dsh-zhiyu-memory/main/market-index.json
```

在「插件 → 实验性插件」里启用自定义插件索引，把这行加进「发现」。有新版本在同一个页面确认更新。

命令行也行：

```sh
dsh plugin --profile web add 'git+https://github.com/sallygulaus-stack/dsh-zhiyu-memory.git#main'
```

装完重启 DSH。

记忆库默认落在 `$DSH_HOME/companion-memory`。想放进别的目录，在 profile 的 `cordis.patch.yml` 里覆盖 `companion-memory` 的 `root`，换目录时把旧数据一起搬过去。

## 你能看见她记了什么

DSH 页面右下角有个小气泡，点开就是记忆列表：每条写了什么、什么时候记的、来自哪句话、被回忆过几次。

登录 DSH 后，也可以直接打开 `/companion-memory/console` 看完整页面，有搜索和按类型筛选。

面板会按已配置的 DeepSeek 模型记录 Token 和人民币估算费用，区分缓存命中、缓存未命中以及空闲/高峰时段。价格表是随版本维护的参考值，不替代供应商账单。
重启后续接旧会话不会重复计费；升级前已经写下的统计记录不会自动重算。

从木偶记忆迁移的条目保留原始来源。旧归档中隔离的条目，只有能从同一会话核验用户原话且与查询命中具体词组时，才作为历史陈述参考；旧摘要和无法核实的模型候选不会自动注入。

历史问题查询不会因为出现“记得”二字就召回全部承诺；无明确主题时也会过滤低词面关联，减少陪伴聊天中的无关插入。

## 一条记忆长什么样

```json
{
  "kind": "relationship",
  "summary": "我们第一次在海边看见了蓝色灯塔。",
  "evidenceRefs": [
    { "turnId": "turn_86d71398", "start": 0, "end": 16, "quote": "我们第一次在海边看见了蓝色灯塔。" }
  ],
  "lastSupportedAt": "2026-11-21T02:39:37.052Z"
}
```

一句话、一条来源、一个时间。没有神秘的向量。

## 它不做什么

**不擦硬盘。** 删除的粒度是「记忆条目」，原始对话、已有归档和备份都还在。它管的是「别再提这件事」，不是「物理上抹掉这件事」。

**不替你备份。** 数据就在磁盘上，那份备份是你自己的事。

**不跨设备同步。** 一台机器一个库。

## 谁适合用

一个人长期跟同一个 AI 相处，希望它记得住，又不希望它把记得的东西越编越离谱。

## 开发

需要 Node.js 22 以上。`npm test` 跑回归，插件入口是 `plugin/lib/index.js`，`src/` 里是参考内核和迁移工具。

发版流程：提版本号并提交 → 打 `v` 标签 → 把版本号、提交 SHA、发布时间追加进 `market-index.json` → 推送索引和标签。
